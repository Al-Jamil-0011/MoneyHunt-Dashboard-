# MoneyHunt Admin Dashboard

## Setup & Run

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Open browser
# http://localhost:3000
```

## Pages
- Dashboard — Overview, live hunt timer, revenue chart
- Users — Manage all users, ban/unban/upgrade
- Hunts & Drops — Create, schedule, activate drops
- Deals — Partner businesses and deal management
- Perks — Community events and opportunity cards
- Map & Locations — Drop zones and business pins
- Merch — Products and inventory
- Orders — Order fulfillment
- Winners & Rewards — Verify and pay winners (matches screenshot)
- Subscriptions — Membership management
- Payments — Transaction history
- Notifications — Push alerts
- Sweepstakes — Weekly cash prize
- Analytics — Charts and stats
- Settings — App config and feature toggles

## Tech Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Recharts (for charts)
- Lucide React (icons)
